# ApexGear Retail Analytics - A simple Excel project Understable to all the employees in Organization

## Project Overview
I started this project to understand how retail data can support better business decisions. Using over 52,000 raw records, I transformed complex data into meaningful insights and an interactive Excel dashboard.

## Live Interactive Dashboard
Explore the Live Project- https://apexgear-retail-analytics.creativestar2.chatgpt.site

## Project Workflow
1. Understanding business requirements
2. Exploring raw data
3. Cleaning and handling missing values
4. Data transformation and feature engineering
5. Exploratory data analysis
6. KPI development
7. Data visualization
8. Interactive dashboard development

## Business Objectives
- Analyze sales and profitability.
- Understand customer purchasing behavior.
- Evaluate product performance.
- Identify business growth opportunities.

## Tools & Skills
Microsoft Excel | Data Cleaning | Feature Engineering | EDA | KPIs | Slicers | Interactive Dashboards

## Key Takeaway
This project helped me understand that data analytics is more than creating charts. It's about asking the right questions, understanding the story behind the numbers, and turning raw data into meaningful business insights.

Feedback and suggestions are always welcome!
